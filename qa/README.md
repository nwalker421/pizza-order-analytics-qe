# Quality Engineering Artifacts

This folder contains the Quality Engineering test management artifacts for the Pizza Order Analytics project.

## QA Test Management Workbook

**Pizza_Order_Analytics_QE_Test_Management.xlsx**

The workbook contains:

- **Test Cases** — detailed functional test scenarios derived from the project requirements and acceptance criteria.
- **Requirements Traceability Matrix (RTM)** — provides traceability between requirements, acceptance criteria, test cases, implementation components, automated tests, and execution results.
- **Test Execution Results** — records test execution evidence, expected and actual results, execution status, defects, and applicable GitHub Actions references.

## Test Automation

Executable automated tests are maintained separately in the `/tests` directory.

Functional requirements and acceptance criteria are maintained in `/docs/requirements.md`.
